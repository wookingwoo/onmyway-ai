## 저장소와 최종 패키지

- [x] 생성한 APK·영상·이미지·문서·압축파일은 로컬에 보관하고 Git 추적에서 제외. CI의 APK 업로드도 비활성화. 아래 APK 업로드 항목은 최종 선택 제출 시 별도로 결정할 사항이며 현재 수행하지 않음.
- [ ] 공개·비공개 전환과 심사자 초대는 본인이 승인한 방식으로 수행. 비공개 개인 저장소 Collaborator는 쓰기 권한도 받는다는 공식 안내 확인.
- [ ] 제출 저장소 README에 앱명·한 줄 소개·실행 방법·테스트 환경·설정·APK 위치 작성.
- [ ] release APK는 공식 안내에 따라 `apk/` 폴더, 파일명 `팀명_앱이름_release.apk`. 개인 참가의 팀명 표기는 익명 조건과 함께 최종 확인.
- [ ] APK를 이메일 단독 첨부하지 않고 소스·APK를 함께 제공하는 GitHub 링크로 제출. 현재 로컬 보관 정책은 유지하며 업로드·접근 부여는 사용자 승인 후 수행.
- [ ] APK 용량 초과 시 실제 GitHub Release와 접근 권한 확인.
- [ ] 신청서 참고자료에는 실제 존재·검증된 파일과 링크만 기재. MAU·리텐션은 가설·목표임을 유지.
- [ ] 최종 파일명과 링크가 이메일 본문·신청서·실제 첨부와 일치.
- [ ] 최종 소스 커밋에서 APK 재빌드·테스트·해시를 기록하고 영상·공식 양식의 기능 범위와 대조. 과거 테스트 수·해시를 최종본 검증으로 대신하지 않음.
- [ ] 본인이 최종 검토 후 메일 발송. 접수 메일과 발송 증거 보관.
