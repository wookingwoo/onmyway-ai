# 말 한마디로, 오늘의 약속까지

한 사람의 퇴근길을 따라가는 공모전 검토용 시연입니다. 준비된 예시 대화와 합성 장소·시간, 모의 안내를 실제 앱에서 실행합니다. 실시간 STT·LLM 성공이나 실제 사용자 효과를 주장하지 않습니다.

## 하나의 생활 장면

오후 6시, 퇴근했습니다. 약은 꼭 사야 하고 맡긴 세탁물은 6시 반 전에 수령을 마쳐야 합니다. 우유도 사고 싶지만 오늘은 7시에 함께 저녁을 먹기로 했습니다. 사용자는 검색창과 시간 입력란을 차례로 채우는 대신 한 번에 부탁합니다.

> 약국은 꼭 들러서 10분 정도 걸릴 것 같아. 맡긴 세탁물은 한결세탁소에서 6시 반 전에 수령을 마쳐야 해. 우유는 시간 되면 사고, 7시까지 집에 가게 적절한 순서로 짜줘.

예시 대화를 독립적으로 선택하면 실제 앱의 자동 준비 흐름과 계획 계산이 실행됩니다. 장소·순서·체류·수령 완료 마감·귀가를 함께 반영한 첫 결과는 18:40 귀가입니다. 별도의 문장 적용·정리·계산 조작을 하지 않습니다. 맡긴 세탁소는 지정 점포로 유지됩니다.

출발 전 상담이 필요하다는 생각이 듭니다. 항목 편집기를 열어 시간을 여러 번 누르는 대신 추가 요청을 합니다.

> 약국에서 상담도 해야 해서 30분은 걸릴 것 같아. 나머지 조건은 그대로 두고 다시 맞춰줘.

추가 예시 요청 뒤 다시 계산 버튼 없이 순서가 바뀝니다. 세탁소 18:06 도착·18:11 수령 완료 → 약국 18:16 도착·18:46 완료 → 집 18:53 도착 예상입니다. 필수 볼일과 마감은 유지하고 선택한 우유만 제외합니다. 이 수치는 합성 데이터의 계산 결과이며 실제 소요 시간 보장이 아닙니다.

사용자는 요약을 보고 ‘확인하고 출발’을 한 번 누릅니다. 공식 AVD의 Drive / 30 km/h에서 앱 조작이 잠기는 모습을 보여 줍니다. Park / 0으로 돌아온 뒤 모의 도착을 보내고, 세탁물 수령 완료는 별도로 확인합니다. 남은 약국 계획은 자동으로 준비됩니다. 약국도 완료하고 마지막 귀가 안내를 별도로 승인해 집 도착까지 이어집니다.

마지막 문장: **“무엇부터 할지, 집에는 언제 갈지. 머릿속으로 맞추던 퇴근길을, 말로 부탁하고 확인하는 일로 바꿉니다. OnMyWay AI.”** 이는 제안하는 효용이며 측정한 성과가 아닙니다.

## 화면과 고지

- 모든 앱 장면에서 **왼쪽 Pleos 차량 패널과 아래 차량 바를 포함한 전체 화면**을 보여 줍니다. 앱 영역만 자르지 않습니다. 상황 문구는 위, 자막은 아래 별도 여백에 둡니다.
- 실제 원본 구간은 1배속입니다. 조회 대기는 축약하고 일부 상태를 정지해 읽을 시간을 주며 이를 계속 표시합니다. 처리 속도를 측정한 영상이 아닙니다.
- 준비된 대화·실제 STT·LLM 아님, 예시 데이터와 모의 안내를 표시합니다. AI 대화·설명 음성은 편집용이며 앱의 음성 출력 기능을 뜻하지 않습니다.
- 실제 모드에서는 최종 음성 인식 결과 뒤 자동 해석·계산이 실행됩니다. 누락된 점포, 모호한 조건과 귀가 시간만 확인하고, 출발·집 위치는 사전 설정이 필요합니다. 정확한 수령 점포 확인과 미확인 영업·서비스 경고는 생략하지 않습니다.
- 실제 한국어 최종 인식, OpenAI/Kakao 인증·응답, 실내비 수락/도착, 물리 차량 검증은 남아 있습니다. 마감 완화·필수 일정 삭제는 이번 음성 수정 범위 밖이며 명시적인 세부 수정이 필요합니다.
- 영상·음성·원본·검증 JSON은 로컬 artifacts/evidence/pleos-service-demo/에만 둡니다. Git에는 재현 소스와 허용된 실제 PNG만 저장합니다. 공개와 제출은 사용자 결정입니다.

실사용과 샘플은 같은 화면·버튼을 사용합니다. 샘플 연결은 설정에서 미리 독립적으로 선택하고, 데이터 출처는 작은 상태 표시로 남깁니다. 시연용 도착 신호 제어는 설정에만 두어 기본 서비스 화면에 노출하지 않습니다. 도착 뒤 ‘완료했어요’가 실제 완료를 뜻하는 한 번의 명시적 확인입니다.

정확한 대사와 문구는 scripts/story_demo.json, 제작 절차는 scripts/STORY_DEMO.md에 있습니다. 이전 story-demo/와 voice-first-demo/ 영상은 역사적 자료이며 현재 제출용 결과와 혼용하지 않습니다.

최종 영상은 약 2분 38초(158.045333초),1920×1080,30fps입니다. 왼쪽 Pleos 차량 화면을 포함한 모든 앱 장면, 주야간 UI, 전체 재생과 디코드 및 자막 29개를 확인했습니다. 영상과 음성은 로컬에만 저장합니다.
