# 오늘의 약속을, 놓치지 않도록

공모전 검토용 한국어 시연 시나리오. 한 사람의 퇴근길을 재구성합니다. 실제 사용자 사례·효과 측정이나 실제 길 안내가 아닙니다. 준비된 해석·가상 장소·시간과 모의 안내를 사용하며 공식 Pleos 앱 화면을 새로 녹화합니다. 설명용 AI 내레이션을 실제 음성 인식처럼 연결하지 않습니다.

## 한 편의 이야기

오후 6시, 퇴근은 했지만 볼일이 남았습니다. 약은 꼭 사야 하고, 맡긴 세탁물은 6시 반까지 찾아야 합니다. 우유는 시간이 되면 삽니다. 오늘은 7시에 함께 저녁을 먹기로 했습니다.

앱은 ‘6시 반 전’이 도착인지 수령 완료인지 묻습니다. 사용자는 수령 완료라고 답하고 귀가 시간을 7시로 정합니다. 세탁물을 맡긴 정확한 점포도 고릅니다. 첫 예시 동선은 6시 40분 귀가입니다.

출발 전 생각해 보니 약국 상담에 10분보다 긴 시간이 필요합니다. 사용자가 직접 체류 시간을 30분으로 바꿉니다. 교통이나 대기를 자동 감지한 상황이 아닙니다. 앱은 세탁소를 먼저 방문하도록 순서를 바꾸고 선택 항목인 우유를 제외합니다. 필수 볼일과 귀가 마감은 유지됩니다.

예시 계산: 세탁소 18:06 도착·18:11 수령 완료 → 약국 18:16 도착·18:46 완료 → 집 18:53 도착 예상. 귀가 마감 19:00, 여유 7분입니다. 이 수치는 합성 데이터의 계산 결과이며 실제 소요 시간 보장이 아닙니다.

다음 목적지를 승인하고 출발합니다. 공식 AVD의 실제 Drive 상태에서는 조작이 잠깁니다. Park으로 복원한 뒤 모의 도착을 보내고, 세탁물을 실제로 찾았다는 뜻의 완료를 별도로 확인합니다. 남은 약국 동선이 자동 갱신됩니다. 약국에서도 완료를 확인하고, 마지막 집 안내도 별도로 승인해 집 도착까지 이어갑니다.

마지막 문장: **“퇴근길에 무엇을 먼저 끝내야 할지, 집에는 언제 갈 수 있을지. 혼자 계산하던 순간을 줄여 줍니다. 오늘의 약속을 놓치지 않도록. OnMyWay AI.”** 사용자 효용은 제안하는 가치이며 측정한 성과가 아닙니다.

## 편집과 검토

- 생활상황 카드 → 실제 앱 → 조건 수정과 판단 → 두 필수 볼일 완료 → 집 도착의 한 흐름입니다. 별도의 두 번째 예시로 전환하지 않습니다.
- 자막·상황 카드·경로 요약은 영상 편집 요소입니다. 앱 알림이나 구현된 지도 화면처럼 보이게 하지 않습니다.
- 중요한 판단 화면은 읽을 시간을 줍니다. 반복 조작과 조회 대기는 축약 표시를 붙여 편집하고, 앱의 처리 속도처럼 주장하지 않습니다.
- 차량 전체 화면은 실제 주행 제한 장면에서 보여 주고, 나머지는 실제 앱 영역을 확대합니다. 원본의 수치·문구·버튼을 바꾸지 않습니다.
- 예시·모의 고지는 계속 표시합니다. 마지막에는 실제 STT·LLM·지도·내비 수락/도착 및 물리 차량 검증이 남았음을 명시합니다.
- 영상·음성·원본·검증 JSON은 로컬 artifacts/evidence/story-demo/에 둡니다. Git에는 제작 소스와 허용된 실제 PNG만 저장합니다. 공개·제출은 별도 사용자 결정입니다.

정확한 장별 문구와 내레이션 원문은 scripts/story_demo.json에 있습니다. 목표 길이는 약 2분 30초~3분이며 최종 음성·가독성 검수 결과를 따릅니다.
