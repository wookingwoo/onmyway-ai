# 말로 부탁하고, 듣고, 출발하는 퇴근길

18시 퇴근. 약은 꼭 사고, 맡긴 세탁물은 18시30분 전에 찾아야 합니다.
우유도 필요하지만 오늘은 19시에 집에서 함께 저녁을 먹기로 했습니다.
하나씩 장소와 시간을 입력하는 대신 한 번에 부탁합니다.

> 약국은 꼭 들러서 10분 정도 걸릴 것 같아. 맡긴 세탁물은 한결세탁소에서
> 6시 반 전에 수령을 마쳐야 해. 우유는 시간 되면 사고, 7시까지 집에
> 가게 적절한 순서로 짜줘.

앱이 계산한 장소·순서·완료 시간과 귀가 예상을 **실제 Pleos 음성**으로
설명합니다. 첫 계획의 귀가 예상은18:40입니다. 상담이 필요하다는 생각이
들면 이어서 말합니다.

> 약국에서 상담도 해야 해서30분은 걸릴 것 같아. 나머지 조건은 그대로 두고 다시 맞춰줘.

다시 계산 버튼 없이 세탁소부터 들르는 계획으로 바뀝니다.18:11 세탁물
수령 완료 →18:46 약 상담·구매 완료 →18:53 귀가 예상입니다. 앱이 바뀐
계획과 우유를 다음으로 미룬 이유를 읽어 줍니다. 필수 볼일과19시 마감은
유지합니다. 이 수치는 합성 데이터의 계산값이며 실제 시간 보장이 아닙니다.

> 이 계획대로 출발해.

현재 계획에 대한 명시적인 출발 의사만 승인합니다. “네”, “출발해도 돼?”,
“출발해, 그런데 약국은30분”을 바로 출발로 처리하지 않습니다. 실제 AVD
Drive/30 상태에서 입력과 화면 조작이 잠기고 음성 안내도 중단됩니다.

정차 후 세탁소 모의 도착을 보내고 **완료했어요**로 수령을 확인합니다.
남은 약국 계획을 앱이 읽습니다. 음성 대답을 명시적으로 시작해 출발을
승인하고, 약국에서도 실제 완료 여부를 별도로 확인합니다. 마지막 집
안내도 다시 **이 계획대로 출발해**로 승인해 집 도착까지 이어집니다.

영상은164.355542초,1920×1080,30fps입니다. 모든 앱 장면에 왼쪽 Pleos
차량 패널과 하단 차량 바를 함께 보여 줍니다. 앱은 같은 서비스 UI를
사용하고 작은 출처 표시만 유지합니다. 음성·화면은 같은 원본 구간을
1배속으로 편집하며 조작 대기는 축약했다고 표시합니다.

앱의 계획 설명은 **기기에서 실제 생성·녹음한 Pleos ON_DEVICE 음성**입니다.
사용자 대사는 독립 선택한 저장 문장이며 영화 음성은 **로컬 Windows Heami**로
준비했습니다. 실제 ASR 성공으로 제시하지 않습니다. 자막은 장면 요약과
준비된 사용자 대사의 문장 단위 편집 자막이며 정밀 인식 타임코드가 아닙니다.
장소·시간은 샘플이고 내비 안내·도착은 모의입니다. 실제 한국어 최종 인식,
OpenAI/Kakao, 실내비 수락·도착과 물리 차량 검증은 남아 있습니다.

키는 지금 필요하지 않습니다. 추후 서버의 무시된 환경 파일에만 추가합니다.
