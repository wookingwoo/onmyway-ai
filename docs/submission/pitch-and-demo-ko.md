# OnMyWay AI 발표와 시연

2026-11-03 설명회 반영. 기존 164.355542초 spoken-plan 영상 기준의 익명 연습 원고이며 제출하지 않았습니다. 실제 PT 발표 시간 제한은 별도 안내를 확인해야 합니다.
기존 HTML 발표 파일은 이 흐름에 맞춰 별도로 다시 제작해야 합니다.
제품·사업 근거는 [전략 문서](../contest-strategy-ko.md), 조작·복구는 [데모 가이드](../demo-guide-ko.md)를 참조합니다.

## 첫 30초

“퇴근길입니다. 약은 꼭 사고, 세탁물은 여섯 시 반 전에 찾아야 합니다. 우유는 시간이 되면 사고 싶습니다. 일곱 시까지 집에 갈 수 있을까요? 가까운 곳부터 가는 것만으로는 수령 완료와 귀가 마감을 함께 지킬 수 있는지 알기 어렵습니다. OnMyWay AI는 귀가 마감이 있는 운전자의 퇴근길 완료 플래너입니다.”

첫 장면은 필수 2개·선택 1개·19시 귀가 조건을 담은 요청과 계산 계획입니다.
시작 전에 “계획 설명은 실제 Pleos 기기 음성입니다. 사용자 대사는 저장 문장과 오프라인 제작 음성이며, 장소·시간·내비 도착은 예시·모의입니다. 실제 STT·LLM·도로 성공 시연은 아닙니다”라고 설명합니다.

## 화면과 숫자

정상 예시는 2026-10-23 18:00 출발 고정입니다. 약 구매 18:05 도착·18:15 완료, 세탁물 18:20 도착·18:25 완료, 우유 18:30 도착·18:35 완료, 집 18:40입니다. 귀가 마감 19:00에 여유 20분이며 모두 합성 데이터입니다.

새 영상에서는 출발 전 약국 체류를 30분으로 직접 바꿉니다. 세탁소 18:06 도착·18:11 완료 → 약국 18:16 도착·18:46 완료 → 집 18:53 예상입니다. 우유는 제외하고 귀가 마감 19:00은 유지합니다. 실제 자동 지연 감지나 실시간 교통 결과가 아닙니다.

별도 보조 예시로 귀가 마감 18:20의 불가능·18:31 조정 흐름도 남아 있습니다. 새 영상의 본편에는 이 다른 여정을 섞지 않습니다.

## 예상 질문과 답변

- **왜 차량인가?** 정차 중 조건 확인, 차량 내 다음 목적지 승인, 실제 주행 제한, 정차 후 완료·귀가를 연결합니다. 최신 구현은 차량 현재 위치로 출발지를 정하고 집을 명시 저장합니다. 공식 AVD에서 수신·권한·주행 경계를 검증했으며 물리 차량 사용성은 남아 있습니다. 영상은 이 후속 위치 변경 전 자료입니다.
- **독창적인가?** 지도 경유지와 전문 시간 창 최적화는 이미 있습니다. 개인의 생활 용무를 질문·확인·완료로 연결하는 차량 경험이 차별화 가설입니다. 세계 최초라고 주장하지 않습니다.
- **AI가 지어내면?** 원문과 해석을 비교·수정하고 필수 누락과 시간 완화를 막습니다. 모르는 정보는 확인 필요입니다. 실제 모델 품질은 키 설정 이후 검증합니다.
- **키 없이 AI를 검증했나?** 아닙니다. 준비된 해석 UI·계산·전체 모의 여정과 제공자 계약의 HTTP 모의 검사를 확인했습니다. 실제 STT 최종 인식·LLM·Kakao는 미검증입니다.
- **늦어지면?** 완료 후 남은 일을 재계산하고 바뀐 계획에는 새 승인을 받습니다. 자동 교통 갱신·자동 우회가 구현됐다고 설명하지 않습니다.
- **영업 중이면 수령 가능한가?** 서로 다릅니다. 현재 Kakao 어댑터는 영업·서비스 가능 여부를 제공하지 않습니다. 키만 넣는 것으로 출시하지 않습니다.
- **필수를 못 하면?** 필수를 보존하고 불가능·정보 부족을 구분합니다. 유효한 변경은 승인 후 반영하며 선택 제외와 계산 근거를 표시합니다.
- **안전이 입증됐나?** 격리 AVD 검증입니다. 물리 차량·차종·지역·카테고리 검사와 사용성 평가가 더 필요합니다.
- **고객과 수익은?** 월 신규 활성 60명·월 재사용 40%면 두 달째 84명 MAU라는 계산 가설이며 실적이 아닙니다. 반복 효용·지불 의사·호출비를 확인한 뒤 과금을 판단합니다.
- **데이터는?** 실제 모드 요청 텍스트·조건이 서버와 설정 제공자로 갑니다. 키는 서버에만 있습니다. 현재 로컬 개발 구조이며 운영 인증·삭제·공유 차량 세션 정책이 출시 전에 필요합니다.
- **SDK 범위는?** STT 3.3.1 ON_DEVICE 초기화·듣기·취소, TTS 3.3.1 ON_DEVICE 실제 한국어 출력, NaviHelper 3.0.5 내비 화면 전환, Android CarUxRestrictions 읽기·Drive 차단입니다. FusedLocation 1.1.3 최신 위치·출발/집 확인 저장은 실제 AVD에서 검증했습니다. Vehicle SDK는 미사용입니다. 타일 HTTP 401·빈 지도여서 실제 경로 성공이라고 하지 않습니다.
- **AI로 개발해도 되나?** 설명회 20:29에서 허용하되 참가자의 구조·로직 이해와 직접 기술 Q&A 설명을 요구했습니다. [기술 카드](briefing-review-ko.md)의 계산·승인·정보 부족·복구를 실제 코드와 연결해 설명합니다.
- **실차가 필요한가?** 설명회 21:04에 따르면 공모전 실차 시연은 지원하지 않고 에뮬레이터로 검증합니다. 공식 AVD·버추얼 콘솔 시연을 준비하며 실제 차량 사용성은 출시 전 별도 과제입니다.
- **제출됐나?** 아닙니다. 영상·APK는 로컬 보관 정책이고 새 debug·unsigned release 빌드는 있으나 과거 서명 제출 APK·영상을 재생성한 것은 아닙니다. 현재 저장소 접근·익명성과 최종 산출물은 사용자가 확인합니다.

## 최신 자료와 과거 자료

`scripts/build-pitch.py`는 실제 스크린샷을 넣은 자립형 한국어 HTML 슬라이드를 로컬 `artifacts/pitch/current/index.html`에 생성합니다. 화살표·이전/다음으로 진행하며 외부 CDN·폰트가 필요 없습니다.

현재 영상 기록은 `artifacts/evidence/spoken-plan/OnMyWay_AI_spoken_demo.mp4`(164.355542초)입니다. 실제 Pleos 한국어 출력·오프라인 준비 사용자 음성·편집 자막을 포함합니다. 검증 기록은 같은 폴더의 `media-verification.json`, 원고는 [spoken-demo-ko.md](spoken-demo-ko.md), 제작은 [SPOKEN_DEMO.md](../../scripts/SPOKEN_DEMO.md)를 참조합니다. 후속 내비 변경 전 녹화이므로 최종 APK와 기능 범위를 다시 대조해야 합니다. 영상과 음성은 Git에 올리지 않으며 이번에 재생·재검수하지 않았습니다. 183.3초 story-demo·107.667초 intent-demo는 이전 영상입니다.
예전 47초·135초 영상 및 기존 DOCX·PPTX·ZIP은 최신 해석 UI 이전 자료이며 그대로 제출하지 않습니다. 공식 DOCX는 최신 `application-ko.md`와 사용자 정보·동의·서명 확인 후 다시 생성·검수해야 합니다.
