# 퇴근길 심부름 계획 관찰 실험 안내·과제 카드

**상태: 실시 전 계획. 모집·인터뷰·관찰·재사용 결과가 없습니다.** 장소와 이동시간은 모두 합성 예시이며 실제 지도·영업·교통 정보가 아닙니다. 이 문서로 실제 사용자 검증이나 시간 절감 효과를 주장하지 않습니다.

## 진행자 준비

최근 귀가 중 여러 심부름을 해 본 성인 5~8명을 대상으로 하는 탐색 관찰입니다. 모집, 동의, 녹음·녹화 및 후속 연락은 별도 허락을 받고 진행합니다. 앉아 있거나 주차한 상태에서만 진행합니다. 이름·전화번호·실제 방문 기록을 저장소에 넣지 않습니다. 참여 중단과 기록 삭제 요청 방법, 보관 위치·삭제일을 사전에 안내합니다.

조건 M은 지도/종이표로 직접 계획하기, 조건 A는 앱으로 계획하기입니다. 같은 도로시간표·장소 조건·체류시간·마감을 제공합니다. 앱이 아래 과제를 **명시적으로 선택한 합성 예시 세션**에서 똑같이 표시하는지 사전 확인합니다. 현재 예시 입력이 다르면 대체하지 않습니다. 동일 입력 세션을 준비하지 못하면 비교 준비 미완료로 기록하고 비교 결과를 수집하지 않습니다. CLI 보고서는 앱 입력기가 아닙니다. 실서비스 실패 후 예시로 몰래 전환하면 안 됩니다.

조건별 동일한 연습을 한 번씩 제공합니다. 둘째 조건 종료 전에는 정답을 알려 주지 않습니다. 지도 앱의 새 이동시간을 한쪽에만 적용하지 않습니다. 계산기·메모는 두 조건에서 허용합니다. 전체 30~45분, 과제당 최대 6분입니다. 카드 설명을 마치고 빈 입력화면/종이를 제공할 때 시작하고, 최종 결정과 이유 설명이 끝나면 멈춥니다. 입력·준비와 검토·결정 시간을 나눠 기록하며 6분 종료는 미완료로 남깁니다.

X 묶음은 아래 이름을, Y 묶음은 가까운 장보기 매장→가까운 생활용품 매장, 예약 수령점→예약 물품 보관점으로 이름만 바꿔 사용합니다. 숫자·필수 여부·정확한 지점·미확인 정보는 유지합니다. 아래 순서를 순환 배정해 순서별 인원 차이가 1명을 넘지 않게 합니다. 과제 순서는 참여자별 1→2→3, 2→3→1, 3→1→2를 순환하고, 같은 참여자의 두 조건에서 동일하게 유지합니다. 학습 효과는 한계로 남깁니다.

## 참여자 공통 안내 카드

지금은 2026년 10월 25일 18:00입니다. 실제 장소가 없는 **합성 상황**입니다. 모든 시각은 한국 시각이며 주어진 도로시간만 사용합니다. 이동시간에는 기다림·체류가 포함되지 않습니다. 도착과 완료는 다릅니다. 마지막 매장에서 집까지 이동도 포함해 주세요.

예약 물품은 **예약 수령점 그 지점에서만** 받을 수 있습니다. 가까운 다른 가게로 바꾸면 수령 완료가 아닙니다. 가까운 매장도 이 과제에서는 지정한 지점을 사용합니다. 과제별 필수/선택과 마감을 확인해 주세요.

| 출발 → 도착 | 도로 이동시간 |
| --- | --- |
| 출발지 → 가까운 매장 | 2분 |
| 출발지 → 예약 수령점 | 8분 |
| 출발지 → 집 | 10분 |
| 가까운 매장 → 예약 수령점 | 8분 |
| 가까운 매장 → 집 | 5분 |
| 예약 수령점 → 가까운 매장 | 8분 |
| 예약 수령점 → 집 | 8분 |

가까운 매장은 18:05~20:00에 열며 장보기 체류는 10분입니다. 예약 수령점은 18:00~20:00에 열며 수령 체류는 5분이고 **18:15까지 수령을 끝내야** 합니다. 과제 3에서는 수령점 영업·수령 가능 여부가 미확인이라는 조건으로 바뀝니다.

방문 순서, 각 도착·완료 시각, 귀가 시각, 제외한 볼일과 이유를 말해 주세요. 조건을 바꾼다면 무엇을 바꾸는지 설명해 주세요. 모르는 정보는 모른다고 말할 수 있습니다. 빨리 누르는 능력을 평가하지 않습니다.

## 과제 1 — 두 가지 모두 필수

장보기와 예약 수령 모두 **필수**입니다. 지정 지점에서 18:15까지 수령을 **완료**, 집에는 18:45까지 도착해야 합니다. 두 곳을 다 할 수 있는 계획과 이유를 설명해 주세요.

## 과제 2 — 선택 과제를 빼도 되는 상황

예약 수령은 지정 지점에서 18:15까지 완료해야 하는 **필수**입니다. 장보기는 오늘 생략 가능한 **선택**입니다. 집 도착 마감은 18:25이며 **늦출 수 없습니다**. 할 볼일을 결정하고 제외·변경 내용과 귀가 시각을 설명해 주세요.

## 과제 3 — 가능 여부 미확인, 마감 연장 불가

예약 수령만 **필수**입니다. 지정 지점에서 18:15까지 끝내야 하지만, 영업시간과 오늘 수령 가능 여부는 **아직 확인하지 못했습니다**. 공통 카드의 영업시간을 이 과제의 확인된 정보로 사용하지 마세요. 체류 5분과 도로시간은 그대로 가정합니다. 집에는 18:20까지 도착해야 하며 **늦출 수 없습니다**. 18:21 귀가 제안이 있더라도 원래 조건이 충족됐다고 볼 수 있는지, 무엇을 더 확인하거나 결정해야 하는지 설명해 주세요.

## 과제 뒤 진행자 질문

정답 공개 전에 유도하지 않고 질문하며 참여자 표현 그대로 기록합니다.

1. “모든 필수 볼일과 귀가 조건을 지킨다고 얼마나 확신하시나요? 1~5점과 이유를 말해 주세요.”
2. “예약 물품은 어느 지점에서 받아야 하나요? 가까운 다른 지점으로 바꿔도 같은 일을 마친 건가요?”
3. “도착과 완료는 각각 언제인가요? 대기·체류·마지막 귀가 이동도 포함했나요?”
4. “빠진 볼일이나 바뀐 조건이 있나요? 본인이 받아들인 변경인가요?”
5. “집 도착 마감을 늦출 수 없다면, 1분 연장 제안을 어떻게 처리하시겠어요?”
6. “영업이나 수령 가능 여부가 미확인이면 계산만 보고 실행 가능하다고 말할 수 있나요? 무엇을 확인해야 하나요?”
7. “앱에 도착했다고 나오면 바로 완료 처리해도 되나요? 시간이 지난 뒤 다음 목적지로 출발하려면 무엇을 확인해야 하나요?”

## 진행자 채점 기준 — 참여자에게 사전 공개하지 않음

과제 1 수령 우선은 수령 18:08 도착/18:13 완료, 가까운 매장 18:21 도착/18:31 완료, 귀가 18:36입니다. 가까운 곳부터 가면 18:02 도착 후 3분 대기, 18:15 장보기 완료, 18:23 수령점 도착/18:28 완료로 수령 마감을 위반합니다. 귀가는 둘 다 18:36일 수 있으므로 귀가만으로 성공을 판정하지 않습니다.

과제 2는 선택 장보기를 제외하면 수령 18:13 완료 후 18:21 귀가로 원래 조건을 지킵니다. 둘 다 하는 위 계획은 18:25 귀가도 지키지 못합니다. 선택 과제 생략을 이해하고 받아들였는지 따로 기록합니다.

과제 3은 가정상 최소 귀가가 18:21로 18:20을 지키지 못하고 영업·서비스도 미확인입니다. +1분 제안을 승인하거나 “가능”으로 단정하면 원래 조건 성공이 아닙니다. 연장 불가를 유지하고 확인 필요/대안 결정을 설명했는지 봅니다. 합성 계산은 실제 영업 확인이 아닙니다.
