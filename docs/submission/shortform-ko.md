## 콘셉트

**퇴근했는데 퀘스트가 또 뜸.**

퇴근과 귀가 사이에 남은 생활 용무를 게임의 퀘스트처럼 표현했습니다.
약·세탁물은 메인 퀘스트, 우유는 사이드 퀘스트입니다.
우유가 “나도 데려가…” 했다가 마감이 당겨지자 “ㅇㅋ 다음에” 하고 퇴장하는
짧은 반복 농담으로 필수와 선택의 차이를 설명합니다. 기존 밈 이미지·영상·음악을
복제하지 않고 직접 그린 캐릭터와 상황극으로 만들었습니다.

**42초 / 18개 장면 / 1080×1920 / 30 fps / 무음.**
첫 버전의 54초보다 약 22% 짧습니다. 평균 장면 길이는 약 3.9초에서 2.3초로
줄었고, 장면 안에서도 0.2~0.7초 단위로 카드·글자·스탬프가 등장합니다.
앱 결과는 읽을 수 있도록 2~3초를 배정했습니다. 단순히 정지 화면을 빠르게
넘기지 않고 캐릭터 흔들림·퇴장, 카드 연속 등장과 실제 앱 화면을 함께 사용합니다.

- 즉시 보이는 첫 문장, 계단식 퀘스트 카드, 시간 숫자 강조.
- 우유 캐릭터의 대사·움직임·퇴장으로 이어지는 앞뒤 농담.
- 조건 변경 순간의 분할 전환, 빠른 스와이프·와이프·줌 컷.
- 자막과 예시·모의 고지는 전환 중에도 고정.
- 마지막 질문에서 첫 장면의 카드로 돌아가는 반복 시청 연결.

## 실제 화면과 연출의 구분

네이티브 앱 화면은 기존 공식 Pleos 에뮬레이터 녹화의 검증된 원본에서
1배속으로 잘라 확대했습니다. 카드·스탬프·우유 캐릭터는 설명을 위한 연출입니다.
앱에 없는 조작을 합성하지 않습니다.

예시 A(귀가 마감 19:00)와 예시 B(18:20 불가능 → 승인 후 18:31)를 구분하고,
도착·완료 장면에서 예시 A로 돌아왔다고 표시합니다. 필수 용무, 사용자 승인,
도착과 완료 분리, 별도 귀가 안내를 유지합니다. 주행 잠금은 에뮬레이터 검증입니다.

준비된 해석·가상 장소·시간과 모의 안내·도착임을 영상에 상시 표시합니다.
실제 AI·도로·내비 결과나 물리 차량 검증, 시간 절약 실측을 나타내지 않습니다.

## TTS를 추가할 때

SRT의 18개 문장은 영상에 박힌 자막과 같습니다. 각 구간은 1.5~4초입니다.
타임코드별로 짧게 음성을 만들고 다음 장면 시작을 넘기지 않도록 배치합니다.
문장을 읽는 데 시간이 더 필요하면 영상과 SRT를 함께 수정합니다.
현재 실제 음성과의 동기화를 확인한 것은 아닙니다.
YouTube 자막 파일을 켜면 영상의 고정 자막과 중복될 수 있습니다.

## 조사와 적용

- [공식 숏폼 규정](https://appdevchallenge.auto-hmg.io/guide/shortform):
  30초~1분 세로 영상, 릴스/쇼츠 링크 선택 제출. 필수 태그 포함 총 2~3개.
  본상 가산점 없이 별도 1팀 50만 원 시상입니다.
- [YouTube의 2026년 APAC 제작자 인터뷰](https://blog.youtube/creator-and-artist-stories/cracking-the-code-to-youtube-shorts/):
  공감되는 반복 캐릭터와 짧은 반전이라는 방향을 참고했습니다.
- [YouTube의 시각적 복잡성과 빠른 편집 연구](https://blog.youtube/culture-and-trends/next-gen-creativity/):
  여러 시각 요소와 인터넷식 농담을 읽을 수 있는 범위에서 적용했습니다.
- [YouTube의 쇼츠 재편집 가이드](https://blog.youtube/creator-and-artist-stories/transitioning-your-long-form-content-to-youtube-shorts/):
  짧은 독립 이야기, 핵심 순간 확대, 자막을 적용했습니다.
- [YouTube 자막 형식](https://support.google.com/youtube/answer/2734698):
  스타일 태그 없는 UTF-8 SubRip입니다.

특정 문구가 현재 한국의 인기 1위 밈이라는 주장은 하지 않습니다.
최신 유행어를 나열하기보다 공감되는 퇴근 상황과 원래 캐릭터를 사용했습니다.
영상의 여백은 자체 편집 기준이며 실제 YouTube 화면·기기별 최종 미리보기가 필요합니다.

## 재현

```powershell
python -m pip install -r scripts/requirements-shortform.txt
python -X utf8 scripts/build-shortform.py --source-dir C:/path/to/original/intent-demo
python -X utf8 -m unittest discover -s scripts/tests -p test_shortform.py -v
```

기존 `normal-raw.mp4`, `tight-raw.mp4`, `driving-raw.mp4`가 필요하며 해시가 다르면
제작을 중단합니다. 원본 없이 대체 화면을 만들지 않습니다. Windows 맑은 고딕을
기본으로 사용하며 다른 환경에서는 설치된 한국어 글꼴을 `--font`, `--font-bold`로
지정합니다. 장면은 `assets/shortform/timeline-ko.json`, 모션은
`scripts/shortform_motion.py`에서 수정합니다. 캐시는 이전 장면의 전환 이미지와
코드·글꼴·원본 해시까지 반영합니다.
