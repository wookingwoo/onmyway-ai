# OnMyWay AI 유튜브 쇼츠

제작일: 2026-10-25. 공개·업로드·접수하지 않은 로컬 제작본입니다.
TTS는 사용자가 나중에 추가합니다. 현재 MP4에는 음악·효과음·음성을 포함한
오디오 스트림이 없습니다.

## 콘셉트

**집엔 7시까지. 할 일은 아직 3개.**

약은 꼭 사고, 세탁물은 수령 마감을 지켜야 하고, 우유는 시간이 되면.
자동차로 귀가하는 사람의 짧은 이야기 안에서 요청 확인, 시간 계산,
승인한 조건 변경과 완료·귀가를 보여줍니다. 기능 목록을 나열하는 대신
귀가 마감이 갑자기 당겨지는 상황으로 차이를 설명합니다.

54초 / 1080×1920 / 9:16 / 30 fps / H.264 / 무음.
남색·흰색·라임을 사용하고 시간 충돌은 주황색으로 구분합니다.
큰 한국어 문장과 실제 앱 화면 확대를 함께 배치했습니다.
영상의 작은 원본 글자를 모두 읽지 않아도 큰 요약 문장으로 이해할 수 있습니다.

제작 스크립트와 검수 기록만 버전 관리합니다.

## TTS를 나중에 붙일 때

SRT는 영상에 표시한 문장과 동일한 14개 자막으로, 일반 UTF-8입니다.
각 구간은 3~6초입니다. SRT의 문장과 타임코드를 기준으로 구간별 음성을
만들고, 다음 장면의 시작 시간을 넘기지 않도록 배치합니다.
낭독이 길면 문장이나 타임라인을 조정하고 영상·SRT를 함께 재생성합니다.
음성을 무리하게 빠르게 만들거나 전체 54초를 자동으로 늘리지 않습니다.
실제 음성이 없으므로 현재 자막을 음성과 동기화했다고 주장하지 않습니다.
유튜브에서 자막 파일도 켜면 영상에 박힌 문장과 중복될 수 있습니다.

제목:

> 집엔 7시까지, 할 일은 3개라면? | OnMyWay AI

설명:

> 약은 꼭, 세탁물은 수령 마감까지, 우유는 시간이 되면.
> OnMyWay AI는 귀가 마감이 있는 운전자를 위한 퇴근길 완료 플래너입니다.
> 필수 용무와 이동·대기·머무는 시간·귀가를 함께 계산하고,

>

> 실제 AI·도로·내비 결과나 물리 차량에서의 검증을 나타내지 않습니다.
>
> 당신의 퇴근길엔 무슨 일이 남았나요?
>
> #HMG차량용앱개발공모전 #PleosAppMarket #OnMyWayAI

공개 계정과 신원 노출, 최종 TTS와 자막, 공개 범위는 사용자가 확인하고
직접 게시합니다. 게시 후 실제 YouTube Shorts 링크를 접수양식 8번에
기입합니다. 현재 링크는 없으며 업로드 성공·조회수·수상을 주장하지 않습니다.

## 조사와 적용

- [공식 숏폼 규정](https://appdevchallenge.auto-hmg.io/guide/shortform):
  30초~1분 세로 영상, 릴스/쇼츠 게시, 링크 선택 제출. 필수 태그 포함 총
  2~3개 태그. 본상 가산점 없이 별도 1팀 50만 원 시상입니다.
- [YouTube 업로드 조건](https://support.google.com/youtube/answer/12779649):
  세로·정사각 영상 최대 3분을 지원하나 이번 제작은 공모전의 1분 상한을 따릅니다.
- [YouTube의 숏폼 제작자 인터뷰](https://blog.youtube/creator-and-artist-stories/youtube-shorts-deep-dive/):
  첫 순간의 관심과 짧은 이야기라는 방향을 적용했습니다. 성과 보장은 아닙니다.
- [YouTube 자막 형식](https://support.google.com/youtube/answer/2734698):
  스타일 태그 없는 UTF-8 SubRip을 사용했습니다.

텍스트의 오른쪽 여백과 하단 여백은 유튜브 버튼·설명 영역과의 충돌을 줄이려는
자체 제작 기준입니다. 기기·자막·유튜브 화면별 차이가 있으므로 실제 업로드
미리보기에서 마지막으로 확인해야 합니다.

## 재현

원본 `normal-raw.mp4`, `tight-raw.mp4`, `driving-raw.mp4`가 있는 로컬 폴더와
Python/Pillow, FFmpeg/FFprobe 및 한국어 글꼴이 필요합니다.
세 원본은 기존에 독립적으로 선택·녹화한 데모이며 해시가 다르면 제작을 중단합니다.

```powershell
python -m pip install -r scripts/requirements-shortform.txt
python scripts/build-shortform.py --source-dir C:/path/to/original/intent-demo
python -m unittest discover -s scripts/tests -p test_shortform.py -v
```

Windows 기본 맑은 고딕을 사용합니다. 다른 환경에서는 설치된 한국어 글꼴을
`--font`, `--font-bold`로 지정합니다. 글꼴은 저장소에 복제하지 않습니다.
장면·원고는 `assets/shortform/timeline-ko.json`에서 함께 수정합니다.
