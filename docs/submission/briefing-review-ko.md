## 직접 설명할 기술 카드

- **AI와 계산의 경계:** FastAPI의 제공자 어댑터가 자연어를 조건으로 구조화하고 사용자가 검토합니다. 결정적 계획기가 후보·방문 순서·선택 용무 부분집합을 탐색하며 이동·영업 시작 대기·체류·최종 귀가를 계산합니다. 최대 용무 5개·후보 3개 범위이고 LLM이 시간 계산이나 내비 출발 권한을 갖지 않습니다.
- **모르는 정보:** 검색된 장소가 영업·수령 가능함을 뜻하지 않습니다. 확인 근거·시각, 도로 데이터가 부족하면 `needs_verification`을 유지합니다. 필수 용무를 조용히 삭제하거나 조건부 시간 연장으로 실행 가능을 확정하지 않습니다.
- **차량 기능의 역할:** Android CarUxRestrictions는 편집·출발 승인·음성의 안전 경계, STT 3.3.1은 입력, TTS 3.3.1 ON_DEVICE는 계산 결과 설명, NaviHelper 3.0.5는 승인한 다음 목적지와 내비 화면 연결입니다. FusedLocation 1.1.3은 최신 차량 위치와 명시적 출발·집 저장에 사용합니다. Vehicle SDK는 미사용입니다.
- **승인의 소유권:** 현재 계획 revision·다음 목적지·유효시간·정차 상태에 승인을 묶습니다. 단순 동의·질문·늦은 콜백·이전 계획으로 출발할 수 없습니다. Drive·상태 미확인은 제한하며 Park 복귀만으로 마이크나 출발 권한을 복원하지 않습니다.
- **완료와 복구:** 도착은 완료가 아닙니다. 실제 할 일 완료 확인 후 남은 계획을 계산하고 다시 승인합니다. 프로세스 중단 후에는 미해결 안내 힌트를 복원하고 새 목적지를 차단합니다. 마지막 집도 별도로 승인합니다.
- **지도 실패의 설명:** SDK 화면 요청과 실제 내비 foreground는 확인했지만 지도 타일 401·빈 화면을 관측했습니다. 실제 도로 표시·목적지 수락·도착을 성공했다고 설명하지 않습니다. [행동·근거](../navigation-handoff.md)를 보여 줍니다.

심사용 기술 문의가 필요하면 다음 사실만 정리해 사용자가 보냅니다: Pleos Connect 2.1.0/API 34, NaviHelper 3.0.5, 설치 내비 3.3.2-rc5-hotfix.3, 내비 권한 3종 granted, 화면 전환 성공, 지도 타일 HTTP 401·빈 화면. 지원 이미지·내비 버전·테스트 네트워크 조건을 문의하며 원시 URL·토큰·로그·개인 좌표는 첨부하지 않습니다. 문의는 발송하지 않았습니다.

새 문서가 있다고 생성 영상·APK·공식 DOCX가 갱신되는 것은 아닙니다. 새 debug·unsigned release APK는 로컬 빌드했지만 기존 서명 제출 APK·영상·DOCX는 재생성·재검수하지 않았습니다. [새 위치 구현과 실제 근거](../location-setup.md)를 참조합니다. [제출 확인표](checklist-ko.md)의 미완료 항목은 그대로 남깁니다.
