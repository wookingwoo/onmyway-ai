# Automotive UX screenshots

Actual full-frame ADB captures from the signed demo release on the official
Pleos Connect 2.1.0 x86_64, API 34 emulator (2560 × 1440, mdpi). The owner expressly
authorized these selected screenshots in Git and the private review PR on
2026-10-24. No screenshots were generated or composited.

The visible journey uses explicitly requested synthetic places, business windows
and road times from the running localhost API. Guidance and arrivals are
simulated, not actual Pleos navigation. The driving overlay is an actual vehicle
restriction response to the official Virtual Console setting Drive / 30 km/h;
the test restored Park / 0 afterward. Dark mode was exercised and restored to
light mode. No API keys, account identifiers or entrant identity are included.
